# Técnicas para Ler Cifras

## 1. Nomenclaturas dos sinais musicais

### 1.1. Notas naturais

| Nota | Cifra |
|:---|:---:|
| Dó | C |
| Ré | D |
| Mi | E |
| Fá | F |
| Sol | G |
| Lá | A |
| Si | B |

### 1.2. Notas acidentais

| Nota | Cifra |
|:---|:---:|
| Dó sustenido | C# |
| Ré sustenido | D# |
| Mi sustenido | E# |
| Fá sustenido | F# |
| Sol sustenido | G# |
| Lá sustenido | A# |
| Si sustenido | B# |
| Ré bemol | Db |
| Mi bemol | Eb |
| Sol bemol | Gb |
| Lá bemol | Ab |
| Si bemol | Bb |

**Observação:** o sustenido (#) eleva a nota em um semitom, enquanto o bemol (b) abaixa a nota em um semitom.

## 2. Sinais de acompanhamento das cifras

| Sinal | Significado |
|:---|:---|
| M ou maj | Maior |
| m ou - | Menor |
| # | Sustenido |
| b | Bemol |
| + | Aumentado |
| ° ou dim | Diminuto |
| 4 | Quarta |
| 6 | Sexta |
| 7 | Sétima |
| 9 | Nona |
| 11 | Décima primeira |
| 13 | Décima terceira |
| sus2 | Suspenso com segunda |
| sus4 | Suspenso com quarta |
| add9 | Nona adicionada |
| ø ou m7(b5) | Meio diminuto |

## 3. Exemplos de interpretação das cifras

| Cifra | Interpretação |
|:---|:---|
| C | Dó maior |
| Cm | Dó menor |
| Dm | Ré menor |
| E7 | Mi com sétima |
| F4 | Fá com quarta |
| A9 | Lá com sétima e nona |
| Bm7 | Si menor com sétima |
| C# | Dó sustenido maior |
| Bb | Si bemol maior |
| C+ | Dó aumentado |
| C° | Dó diminuto |
| Dsus2 | Ré suspenso com segunda |
| Gadd9 | Sol com nona adicionada |
| Bm7(b5) | Si meio diminuto |
| Cmaj7 | Dó maior com sétima maior |

## 4. Outros sinais encontrados nas cifras

| Sinal | Significado |
|:---|:---|
| / | Indica uma nota diferente no baixo |
| ( ) | Indica alteração ou complemento da cifra |
| % | Pode indicar repetição do compasso anterior |
| N.C. | Sem acorde (No Chord) |
| X | Pode indicar corda abafada ou que não deve ser tocada |

### Exemplos de cifras com baixo diferente

| Cifra | Interpretação |
|:---|:---|
| C/E | Dó maior com Mi no baixo |
| G/B | Sol maior com Si no baixo |
| D/F# | Ré maior com Fá sustenido no baixo |
| Am/G | Lá menor com Sol no baixo |

## 5. Dicas rápidas para leitura

- Quando aparecer somente a letra, o acorde é maior.
- Quando aparecer a letra acompanhada de `m`, o acorde é menor.
- Quando aparecer `7`, indica uma sétima.
- Quando aparecer `#`, a nota é elevada em um semitom.
- Quando aparecer `b`, a nota é abaixada em um semitom.
- Quando aparecer `/`, observe qual nota deverá ser executada no baixo.
- Quando aparecer `sus`, o acorde possui uma suspensão.
- Quando aparecer `add`, significa que uma nota foi adicionada ao acorde.

**Importante:** em cifras como C9, a sétima normalmente também está presente. Já em Cadd9, a nona é adicionada sem exigir a sétima.

## Sinais de Acompanhamento das Cifras

|---|---|
| M ou +| Maior |
| m ou - | Menor |
| # | Aumentado ou Sustenido |
| b | Bemol |
| 4 | Quarta |
| 6 | Sexta |
| 7 | Sétima |
| 9 | Nona |
| 11 | Décima Primeira |
| 13 | Décima Terceira |
| SUS2 ou add9 | Acorde Suspenso - Nona Adicionada |
| SUS4 | Acorde Suspenso - Quarta Adicionada |
| ∅ ou m7(b5) | Meio Diminuto ou Menor com sétima e quinta Bemol |
| O | Diminuta |

### Exemplo dos sinais que acompanham as notas

|---|---|
| C | Dó maior (nesse caso, não precisa ter o "M" |
| Dm | Ré menor |
| E7 | Mí com sétima |
| F4 | Fá com Quarta |
| A9 | Lá com Nona |
| Bm7(#9) | Sí menor com Sétima e Nona que Aumentada |
